# daily-reports/

รายงาน Demand/Supply ที่สแกนอัตโนมัติทุกเช้า (ประมาณ 07:00 น. เวลาไทย) จะถูกบันทึกไว้ที่นี่
เป็นไฟล์ชื่อ `YYYY-MM-DD.md` หนึ่งไฟล์ต่อวัน

แต่ละไฟล์มี:
- **สรุปผู้บริหาร** — คู่ demand/supply ที่น่าติดต่อที่สุดของวันนั้น
- **Demand ที่พบ** — โพสต์/ประกาศหาซื้อบ้าน/ที่ดิน/คอนโดในเชียงใหม่ ลำพูน ลำปาง ที่ค้นเจอจากเว็บสาธารณะ
- **Supply/ราคาตลาดที่พบ** — ประกาศขายใหม่จากเว็บอสังหาฯ สำหรับเทียบราคาตลาด/คู่แข่ง
- **แหล่งที่มา** — ลิงก์อ้างอิงของทุกรายการ ให้ตรวจสอบก่อนติดต่อจริงเสมอ

⚠️ เป็นข้อมูล best-effort จาก Web Search สาธารณะเท่านั้น (ไม่ได้ล็อกอินหรือดึงข้อมูลจาก Facebook/Line/TikTok
โดยตรง เพราะแพลตฟอร์มเหล่านี้ไม่เปิด API แบบนั้นและมีความเสี่ยงเรื่อง ToS) ไม่ครอบคลุมทุกโพสต์ที่มีจริง
และควรตรวจสอบความถูกต้อง/ความเป็นปัจจุบันของแต่ละรายการก่อนติดต่อลูกค้าเสมอ
