# data/listings.json

ไฟล์นี้คือ "โปรไฟล์ทรัพย์ของฉัน" แบบที่ commit เข้า repo ได้ ใช้เป็นข้อมูลสำรอง/ที่เก็บกลางที่แชร์กับ
ใครก็ตามที่ทำงานกับ repo นี้ (เช่นให้ Claude ช่วยเพิ่ม/แก้ทรัพย์ผ่านแชทได้โดยตรง)

เดิมไฟล์นี้ถูกออกแบบมาให้ Routine สแกนอัตโนมัติทุกเช้าอ่านไปจับคู่กับ demand ที่เจอจาก Web Search
แต่ฟีเจอร์สแกนอัตโนมัตินั้นถูกตัดออกแล้ว (ดูเหตุผลใน `../README.md` หัวข้อ "เกี่ยวกับการสแกนอัตโนมัติ")
เพราะ Web Search ในเซสชันคลาวด์ให้ผลลัพธ์ไม่แม่นยำพอ ตอนนี้ไฟล์นี้จึงเป็นแค่ backup ของทรัพย์เท่านั้น
ไม่มีอะไรมาอ่านมันโดยอัตโนมัติ

## วิธี sync จากแอป (ถ้าต้องการเก็บ backup ไว้)

1. เปิด `index.html` → แท็บ "ข้อมูล" → กด "Export เป็นไฟล์ JSON"
2. เปิดไฟล์ที่ได้ จะมีโครงสร้าง `{ "listings": [...], "leads": [...] }`
3. คัดลอกเฉพาะ array ของ `listings` มาวางแทนที่เนื้อหาในไฟล์นี้ (`data/listings.json`)
4. Commit + push ไฟล์นี้เข้า repo

## รูปแบบข้อมูลแต่ละรายการ

```json
{
  "id": "รหัสอะไรก็ได้ที่ไม่ซ้ำ",
  "title": "บ้านเดี่ยว 2 ชั้น หมู่บ้านสายลมจอย",
  "type": "บ้าน",           // บ้าน | ที่ดิน | คอนโด | ทาวน์โฮม
  "status": "available",     // available | reserved | sold  (สแกนจะดูเฉพาะ available)
  "province": "เชียงใหม่",   // เชียงใหม่ | ลำพูน | ลำปาง | อื่นๆ
  "district": "สันทราย",
  "price": 3500000,
  "sqm": 150,
  "bedrooms": 3,
  "bathrooms": 2,
  "rai": null, "ngan": null, "wa": null,   // ใช้เมื่อ type = "ที่ดิน"
  "description": "จุดเด่นของทรัพย์",
  "contact": "โทร 08x-xxx-xxxx หรือ Line: xxxx"
}
```

เก็บเป็น array `[ {...}, {...} ]` ถ้ายังไม่มีทรัพย์ให้ปล่อยเป็น `[]` ตามค่าเริ่มต้น
