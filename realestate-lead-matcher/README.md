# ตัวช่วยหาลูกค้าอสังหาฯ (เชียงใหม่ / ลำพูน / ลำปาง)

เว็บแอปหน้าเดียว (ไม่ต้องติดตั้งอะไร) สำหรับ:

1. เก็บทรัพย์ในมือ (บ้าน / ที่ดิน / คอนโด / ทาวน์โฮม)
2. เก็บลูกค้าที่สนใจซื้อ โดยวางข้อความที่เจอจากโพสต์/คอมเมนต์บน Social แล้วระบบช่วยแยกความต้องการ (ประเภท, ทำเล, งบประมาณ) ให้อัตโนมัติด้วย heuristic ภาษาไทยง่ายๆ
3. จับคู่ลูกค้ากับทรัพย์ที่ตรงความต้องการ พร้อมปุ่มคัดลอกข้อความนำเสนอไปส่งต่อทาง Line/Messenger ได้ทันที

## ข้อจำกัดที่ควรรู้

**เครื่องมือนี้ไม่ได้เชื่อมต่อ Facebook / Line / TikTok / Instagram API เพื่อดึงโพสต์หรือค้นหาผู้ใช้แบบอัตโนมัติ** เนื่องจาก:

- แพลตฟอร์มเหล่านี้จำกัดการเข้าถึงข้อมูลผู้ใช้ผ่าน API อย่างเข้มงวด (ต้องขอสิทธิ์ business/app review)
- การสแกน/ดึงข้อมูลส่วนบุคคลของผู้อื่นโดยไม่ได้รับอนุญาตอาจขัดกับข้อกำหนดการใช้งาน (Terms of Service) ของแพลตฟอร์ม

**วิธีใช้งานจริง:** เมื่อคุณเจอโพสต์หรือคอมเมนต์ที่มีคนหาบ้าน/ที่ดิน/คอนโด ให้คัดลอกข้อความนั้นมาวางในช่อง "วางข้อความจาก Social" ในแท็บ "ลูกค้า" ระบบจะช่วยแยกประเภททรัพย์ จังหวัด/อำเภอ และงบประมาณให้อัตโนมัติ จากนั้นตรวจสอบ/แก้ไขก่อนบันทึก

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม หรือจะโฮสต์แบบ static site (เช่น GitHub Pages) ก็ได้:

```bash
# เปิดตรงบนเครื่อง
open realestate-lead-matcher/index.html   # macOS
# หรือรันเซิร์ฟเวอร์เล็กๆ
npx serve realestate-lead-matcher
```

## ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมด (ทรัพย์ + ลูกค้า) เก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้นๆ เท่านั้น **ไม่มีการส่งข้อมูลออกไปที่เซิร์ฟเวอร์ใดๆ**

- ใช้ปุ่ม "Export เป็นไฟล์ JSON" ในแท็บ "ข้อมูล" เพื่อสำรองข้อมูลเป็นระยะ
- ใช้ "Import จากไฟล์ JSON" เพื่อย้ายข้อมูลไปเปิดในเครื่อง/เบราว์เซอร์อื่น

## เกี่ยวกับการสแกนอัตโนมัติ (ทดลองแล้ว, ตัดออก)

เคยลองทำ Routine สแกน Demand/Supply อัตโนมัติทุกเช้าโดยใช้ Web Search จากเซสชันบนคลาวด์ แต่พบว่า:

- WebSearch ที่ใช้ได้ในเซสชันคลาวด์ให้ผลลัพธ์ตื้นกว่าการเข้า Google เองมาก (แค่สรุปจาก snippet ไม่กี่รายการ)
- เว็บอสังหาฯหลักแทบทั้งหมด (DDproperty, FazWaz, Livinginsider, Dot Property, KUMUANG, ฯลฯ) ถูกบล็อกโดย network proxy ของ environment ทำให้ WebFetch เข้าไปอ่านหน้ารายละเอียดจริงไม่ได้
- ผลคือรายงานที่ได้ไม่แม่นยำพอจะใช้งานจริง (บางครั้งแม้ session จะรายงานว่า "สำเร็จ" ก็ยังไม่ได้ push รายงานจริงด้วยซ้ำ)

จึงตัดฟีเจอร์นี้ออก **ทรัพย์ของคุณยังคงอยู่ใน [`data/listings.json`](data/listings.json)** เป็นข้อมูลสำรองที่ commit เข้า repo ได้ (ดู [`data/README.md`](data/README.md)) แต่ไม่มีการสแกนอัตโนมัติอีกต่อไป

**วิธีใช้งานที่แนะนำแทน:** เมื่อคุณเจอประกาศหรือคนหาซื้อบ้าน/ที่ดิน/คอนโดเอง (จาก Social, เว็บอสังหาฯ, หรือ Google) ให้คัดลอกข้อความ/ลิงก์มาวางในแชทหรือในแท็บ "ลูกค้า" ของแอป ให้ระบบช่วยแยกข้อมูลและจับคู่ให้ — แม่นยำกว่าให้ระบบไปค้นหาเองมาก

## แนวทางพัฒนาต่อ (ถ้าต้องการ)

- เชื่อม Facebook Graph API / Line Messaging API แบบเป็นทางการ (ต้องสมัคร Business + ผ่าน App Review) เพื่อรับข้อความจากลูกค้าที่ทักเข้ามาโดยตรง แล้ว auto-parse เข้าระบบ
- ทำเป็น backend + ฐานข้อมูลจริง หากต้องใช้งานหลายคน/หลายเครื่องพร้อมกัน
- เพิ่มระบบแจ้งเตือน (LINE Notify / email) เมื่อมีลีดใหม่หรือทรัพย์ใหม่ที่ตรงกับลีดที่ยังเปิดอยู่
